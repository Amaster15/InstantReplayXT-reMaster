Instant Replay XT for OBS Studio 31 and newer

Close OBS Studio before continuing.

The recommended installation folder is the standard shared OBS plugin folder:
C:\ProgramData\obs-studio\plugins\InstantReplay

Setup now offers a destination folder selector. Keep the default unless you have configured OBS to search another plugin location. The final folder must be named InstantReplay. Selecting an arbitrary folder does not make OBS load plugins from it. This option does not set the replay video folder. Upgrades remember your previous destination; uninstall before moving an existing installation.

This is for standard Windows x64 OBS installations, including Windows 10 with OBS 32. Portable OBS is not supported by this installer; use the ZIP package for portable installations.

If you previously installed InstantReplay.dll in your OBS application's obs-plugins\64bit folder, move that old DLL out first. Do not leave two copies installed. A previous DLL in the standard destination is backed up outside OBS's plugin search folders before replacement.

Restart OBS after installation. Open Tools > Instant Replay XT Settings.
Bind "Instant Replay XT: Save replay" and "Instant Replay XT: Play latest replay" separately. Automatic switching is off by default; enable its checkbox in plugin settings if desired. Do not bind that same key to OBS's Save Replay action.

Uninstall through Windows Settings > Apps > Instant Replay XT for OBS.
Your OBS scenes, profiles, replay recordings and plugin backups are preserved.

This installer is unsigned. The build has passed compilation and dependency checks; live replay testing on your own OBS setup is still required.
